Configuration

YAML config with ${ENV_VAR} substitution: providers, model routing, failover, caching, plugins, and app keys. Changes hot-reload without a restart.

For now: the annotated config.example.yaml.

App keys

Vend btr_ keys with expiry and model/provider scopes, rotate or revoke them, and track per-key token usage, streaming included.

For now: the app key design doc.

Plugins

Pre/post HTTP and LLM hooks. Write external plugins in any language that compiles to WebAssembly; they run in an Extism/wazero sandbox with per-hook timeout and memory caps.

For now: the example plugin and the prompt-injection guard docs.

Butter

A fast AI proxy gateway, inspired by Bifrost. Apache-2.0. Signed releases with SLSA provenance and SBOMs.
